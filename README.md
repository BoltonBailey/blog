
# Posted at Quantum Milkman

This folder contains Markdown files for blog posts I have already posted at Quantum Milkman.

[Sitemap here](./sitemap.md). [Source here](https://github.com/BoltonBailey/blog)

I don't intend to convert these to HTML in any way, all of the static site generators I have tried have had issues. If you would like to read a webpage-like versions of these posts, you can

* Visit [Quantum Milkman](https://quantummilkman.com), a substack blog where I post these articles.
* Use a Markdown viewer or converter of your choice to read these files. I like the [md-reader](https://github.com/md-reader/md-reader) [Chrome extension](https://chromewebstore.google.com/detail/markdown-reader/medapdbncneneejhbgcjceippjlfkmkg) for this purpose (other extensions available in other browsers).
